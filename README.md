# Alion Freebies

Free Claude skills and prompts for media buyers and lead gen teams.

| Freebie | What it does |
| --- | --- |
| [Cost per FTD](cost-per-ftd) | Joins your ad spend and lead exports to show what each FTD really cost, by campaign and ad set |
| [Meta vs real leads](meta-lead-gap) | Compares Meta's lead count with the leads you actually received, day by day, and flags when the gap opens |

Each folder has a README with setup steps and sample files to test with.

Made by [Alion](https://alion.app), a lead distribution platform. Free for your first 100 leads a month.
